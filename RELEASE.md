# Augusinh — GitHub Pages release

Gói mã nguồn này đã sẵn sàng cho tài khoản GitHub `osavietnam`, repository `osavietnam`, với base path `/osavietnam`.

1. Giải nén toàn bộ nội dung vào nhánh `main` của repository.
2. Trên GitHub, vào **Settings → Pages → Build and deployment** và chọn **GitHub Actions**.
3. Push lên `main` hoặc chạy thủ công workflow **Deploy GitHub Pages** trong tab Actions.

Website được xuất bản tại:

`https://osavietnam.github.io/osavietnam/`

Mỗi lần Action build, phần tin Trung ương Dòng và Tỉnh Dòng được lấy lại thành snapshot tĩnh. GitHub Pages không hỗ trợ proxy/server runtime nên nội dung này chỉ cập nhật khi deploy lại; liên kết bài nguồn sẽ mở website gốc.
